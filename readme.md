# Assignment 2: Pokémon App - Home Page and Admin Dashboard

In this assignment, you will complete two major features of your Pokémon App:

- [Epic 1: Home Page Experience](https://github.com/comp2537-s26/comp2537-s26-course-reader/blob/main/Week-0-Pokemon-App/specs.md#epic-1-home-page-experience)
- [Epic 5: Admin Dashboard](https://github.com/comp2537-s26/comp2537-s26-course-reader/blob/main/Week-0-Pokemon-App/specs.md#epic-5-admin-dashboard)

### Requirements:

- Build the Home Page to display a list of Pokémons with the ability to search, filter by type, sort by name or type, and paginate the list.
- Create the Admin Dashboard that allows admin users to:
  - View all users
  - Delete users
  - Edit user information

### Notes:

- Ensure the Home Page is user-friendly, responsive, and intuitive for browsing Pokémons.
- Pagination should limit the number of Pokémons displayed per page.
- The Admin Dashboard should be accessible only to admin users after logging in.
- Admins use the same login page as regular users but see additional admin options once logged in.

### Demonstration:

You will demonstrate a working Home Page and Admin Dashboard during lab time. Be prepared to show user browsing features and admin management actions.
